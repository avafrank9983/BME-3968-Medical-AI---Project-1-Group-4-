# Results Directory

This folder stores generated visual and quantitative outputs from analysis notebooks.

## Current subfolders
- `eda_figures/`: plots generated by `Notebooks/eda.ipynb`
- `modeling_figures/`: plots generated by `Notebooks/modeling.ipynb`

## Guidance
- Keep figure filenames descriptive and stable.
- Prefer saving plots with `dpi>=120` and `bbox_inches="tight"`.
- If tables are exported, place them in a dedicated subfolder such as `tables/`.
